# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All contributors and maintainers are expected to follow it in issues, pull
requests, discussions and every other project space.

In short: be respectful and constructive, assume good faith, and do not harass anyone.

## Reporting

Report unacceptable behavior privately to the maintainer, [@rphang](https://github.com/rphang),
using a private contact listed on the maintainer's GitHub profile. If there is none, open a private
[security advisory](https://github.com/rphang/opencode-workflows/security/advisories/new) and say
that it is a conduct report. Reports are handled confidentially. Enforcement follows the
Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
